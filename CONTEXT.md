# Today in Cinema

A site that tells you whether a given date is explicitly referenced within a movie or show (not a release date), competing on footprint, corpus size, crowdsourcing, and visual skins simultaneously.

## Language

**Footprint**:
The bytes a browser downloads to render a page load — HTML shell, core CSS/JS, the active skin's CSS(+JS), and the day's JSON response. Scoped entirely to the client; backend dependency choices and binary size are not part of it.
_Avoid_: "lightweight," "minimal," applied to the backend/server.
